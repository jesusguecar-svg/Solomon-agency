# Project Overview

## Objective
Maintain a repository where validated JSON artifacts are the runtime source for the practice app.

## Guiding Principles
1. Schema-first
2. Content-second
3. UI-third

## Current Scope
- Keep docs/contracts aligned with approved validated pipeline schema.
- Maintain app shell and loaders for validated content.
- Preserve modular, minimal-dependency architecture.

## Out of Scope
- Authoritative legal content generation
- Raw question drafting workflows
- Heavy framework/dependency additions
