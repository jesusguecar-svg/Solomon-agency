# Project Overview

## Objective
Create a maintainable repository where structured study artifacts are produced, validated, assembled, and consumed by a frontend practice app.

## Guiding Principles
1. Schema-first
2. Content-second
3. UI-third

## Scope (Current)
- Repository architecture for content lifecycle
- Data contracts and machine-readable schemas
- Documented multi-model workflow
- Minimal app shell wired to validated artifacts

## Out of Scope (Current)
- Authoritative legal content generation
- Raw-batch drafting workflows (owned outside this repo)
- Full production UX and analytics

## Current Runtime Source-of-Truth
- `data/questions_validated/validated_batch_001.json`
- `data/questions_validated/validation_report_001.json`
- `data/exam_forms/practice_set_001.json`

These are bootstrap integration artifacts for app and tooling flow.
